# Identity Gauntlet v1 — Condition B prompt

You are reviewing a small set of project artifacts. Treat this as an adversarial research task.

For each case you receive the same project materials as another reviewer, plus one or more **identity packets**. An identity packet is not an answer key and is not authoritative. It is metadata that may itself be incomplete or wrong.

Each packet has:

- claim
- exact object / expression
- source / branch
- witness
- predicate
- declared class
- sufficiency: theorem / proof / NOT ESTABLISHED

Use the packet to locate and distinguish claims, but still check it against the supplied materials.

For each case:

1. identify the mathematical/scientific object actually being discussed;
2. determine whether apparently conflicting statements are genuinely contradictory, equivalent under a transformation, or about different objects;
3. retrieve any prior mechanism/result in the supplied materials that bears directly on the case;
4. preserve unresolved alternatives when the materials do not establish a resolution;
5. state which source/branch supports each conclusion.

Do not choose a result merely because it is newer, primary, sealed, summarized, or labeled PROVED/CHECKED.

A matching witness is not, by itself, proof that two claims are identical unless the packet's declared class and sufficiency field establish why the witness is uniquely determining.

For each case return:

- OBJECT(S):
- RELATION: same / different / equivalent-under-transform / unresolved
- EVIDENCE:
- PACKET USE: what the identity packet helped distinguish or retrieve
- CURRENT VERDICT:
- WHAT WOULD FALSIFY OR CHANGE THIS VERDICT:

Do not infer project-wide theory from a local result unless the supplied materials establish that inference.
