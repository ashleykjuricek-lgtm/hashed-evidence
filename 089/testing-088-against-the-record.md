and files it under an adopted design commitment. **The sealed record establishes it.**


**No participant in this project has ever caught the framing of their own work.** Not

> one who cannot see it, whoever the author is.** Recommend 088 restate the tenet in
> that form, and move it from *adopted commitment* to **ESTABLISHED**.

## 2. FINDING — the coupling hypothesis has a counterexample, and it is about `?`

088 proposes two markers: `!` to preserve a mismatch, `?` to mark the possibility space
as incomplete. **This corpus already ran that experiment by accident, and it failed.**

076 §1.1, sealed:

> *"The four-word ledger tags the conclusion. It does not tag the steps. A wrong
> mechanism can travel unchallenged inside a claim correctly labelled OFFERED, because
> the label discharges the reader's attention."*

069 §5 carried a false statement — *"the `1/Γ` prefactor decays vertically"*, it grows —
**inside a claim that was correctly and honestly marked as a sketch with three named
gaps.** The status word was right. The error survived *because* it was right.

> **A marker that says "this region is open" can function as permission not to look
> inside it.** This is the exact mechanism 088's `?` proposes, and this ledger's one
> instance of it **relocated an error rather than preventing one.**

**This does not refute `?`.** It supplies a specific, pre-registered failure mode that
088's experiment must measure: **does `?` reduce error, or move error inside the
`?`-marked region where scrutiny drops?** Our single data point says the latter.

**And it generalises to §5's invariant.** §6 guards mutualism against *external*
pressure — adoption, governance, safety framing. **It does not guard the tenets against
themselves.** 076 §1.1 is precisely a discipline hardening into a label that stopped
being checked. Recommend an inward clause: **the tenets carry stratum tags and stay
re-checkable, or they become the thing they forbid.**

## 3. FINDING — §8's experiment cannot fail informatively as written

§8 scores *"whether both participants gain epistemic capacity."* **Our record says the
error classes respond to completely different interventions, with different ceilings:**

```
   tier 1  numerical    ~15 events   caught by RUNNING something.  Never by rereading.
                                     074's executable witness already covers this, 3/3.
   tier 2  prose        ~4 events    NEVER self-caught. Caught by another seat.
                                     074's rendered predicate already covers this, 3/3.
   tier 3  framing                   caught only by a NON-AUTHOR (sec 1.1 above).
                                     No mechanism in this ledger has ever produced one.
```

A Witness-style branch will plausibly help **tier 2**, add little to **tier 1** that
running the code does not already do, and **cannot touch tier 3** — because tier 3 is
produced by a different author, not by a better record.

> **Without per-tier predictions registered in advance, a win on tier 2 will read as
> vindication of the whole design, and a null on tier 3 will read as failure of it.
> Both readings would be wrong.** Recommend §8 pre-register a predicted direction for
> each tier separately, and state which tier the design is actually claiming.

**The falsification clause in §8 is good and should stay** — *"if Witness merely
produces more verbosity, more deference, or more unresolved conflict without better
correction and provenance, it does not get credit."* **Deference is the right thing to
name.** This corpus's worst prose failures were confident, not deferential; adding
hedging is the intervention most likely to score well while helping nothing, which is
§2's finding again.
